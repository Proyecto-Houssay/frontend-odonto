# Inicio — Frontend Novadent

Novadent organiza la atención odontológica con módulos conectados al backend. Esta Wiki reúne propósito, criterios de integración y flujo de trabajo del frontend.

## Propósito

Facilitar el acceso del equipo a pacientes, profesionales, agenda e información clínica de acuerdo con su rol, manteniendo una experiencia clara y consistente.

## Principios

- La API del backend es la fuente de verdad en modo conectado.
- Los mocks se identifican como demostración y nunca se confunden con registros reales.
- Las rutas y acciones respetan la sesión y permisos informados por backend.
- Los datos clínicos se muestran solo a usuarios autorizados.
- El odontograma actual tiene alcance académico hasta que exista persistencia clínica confirmada.
